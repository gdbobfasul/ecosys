Pupikes Текстові інструменти — Повний текстовий верстат — офлайн, на пристрої.

Включені інструменти:
• Текстові інструменти — Лічильник, форматування, Base64
• Регістр і рядки — ВЕЛИКІ/малі/Заголовок, сортування, без дублів, нумерація, slug
• Кодування/декодування — URL, HTML, ROT13, Морзе, двійкове, шістнадцяткове
• Генератори — Пароль, UUID, Lorem ipsum, SHA-хеші
• Витягання — Ел. пошти, URL, числа, хештеги, згадки, IP
• Різниця (diff) — Порівняй два тексти по рядках — додано/видалено
• Unicode стиль — жирний, з̶а̶к̶р̶е̶с̶л̶е̶н̶о̶, п̲і̲д̲к̲р̲е̲с̲л̲е̲н̲о̲ — для соцмереж
• JSON / CSV — Формат/стиснення/перевірка JSON та JSON↔CSV
• Частота слів — Найчастіші слова зі смугами + всього/унікальних/символів
• Римські цифри — Число ↔ римське (1–3999), автовизначення
• Системи числення — Двійкове / вісімкове / десяткове / шістнадцяткове (BigInt)
• Перенос і префікс — Перенос на N символів, префікс рядка (цитата/коментар), розгорнути
• Кольори — HEX ↔ RGB ↔ HSL зі зразком і вибором
• Мітка часу — Unix ↔ дата (місцева/UTC/ISO), кнопка «Зараз»
