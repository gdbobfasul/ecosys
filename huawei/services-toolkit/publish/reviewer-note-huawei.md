## For reviewer

To address the feature-depth note, a new distinctive "Combined tools" (Комбинирани инструменти) section was added — capabilities a generic toolkit lacks: a chained text transformer (build an ordered pipeline of steps, see output after each, save named pipelines), a batch unit converter (convert a whole list of values at once), and a batch data generator (UUIDs, passwords, Lorem, ranges). All fully offline, localized. This differentiates it from ordinary utility boxes.
