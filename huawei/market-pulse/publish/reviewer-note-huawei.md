## For reviewer

This update adds a distinctive new main feature: a **Liquidation Heatmap** tab. It is an educational tool that reads public market data (Binance public endpoints: price, open interest, recent candles — no account, no API key, no trading) and computes, per cryptocurrency, where leveraged-position liquidation levels pile up around the current price. It shows: the current price at the top, a color heatmap of accumulated liquidity (bright yellow = the largest cluster), which side (above/below) holds more liquidity and at which price values, an educational probability of where price may lean (calibrated against the app's own accumulated history), an optional periodic local notification, and a historical table. The user can add currencies from a list (BTC, ETH, UNI, ZEC, LTC, SOL, ADA, DOGE and more). All 15 UI languages are covered.

This is an EDUCATIONAL model derived from public data — it is clearly labeled as NOT investment advice and NOT real exchange data, the app has no account, no wallet, no trading and no payments.

An earlier update also added an offline "Tools" section with real financial calculators (compound interest, loan/mortgage payment, position-size/risk), pure on-device math with no network. Together these add distinctive, deeper functionality that differentiates the app.
