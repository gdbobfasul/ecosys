# pupikes-toolkit-passwords — Reviewer note (Huawei AppGallery)
Version 1.0021

## For reviewer
Reply to rule 4.1 ("only simple content").
Version 1.0021 turns the single generator into a PASSWORD SUITE (9 tools, all on the device, no account): 1) Password analyzer — entropy in bits, estimated crack time for offline (10 billion/s) and online (100/s) attacks, detected weaknesses (too short, digits/lowercase only, keyboard/alphabet sequences, repeats, years, dictionary words, most common passwords) and an optional leak check against Have I Been Pwned using k-anonymity (only the first 5 characters of the SHA-1 hash leave the phone; if the public API is unreachable the request goes through our own relay). 2) Passphrase — random dictionary words in 6 languages (EN/BG/RU/DE/ES/FR), separator, capitalization, digit+symbol, 5 variants with their entropy. 3) Bulk passwords + policy — up to 100 passwords at once by rules (length, character sets, no ambiguous 0O1lI, no repeated neighbours), each rated, CSV export / copy all — for administrators and teams. 4) Generator — 9 methods (random, words, PIN, pronounceable, pattern template, leet from a phrase, acronym from a sentence, mnemonic, PIN+word) with a verdict weak/medium/strong/very strong and a percentage. 5) Text encryption — AES-256-GCM with a password (PBKDF2); encrypted text can be sent anywhere. 6) Hashes & encoding — SHA-256/384/512, HMAC, Base64/Hex/URL encode/decode, and a deterministic site password derived from a master password (PBKDF2, nothing stored). 7) Browser passwords — tabs phone/computer for Chrome, Edge, Firefox, Safari, Opera, Brave, Samsung Internet with the exact export/import steps, plus loading the browser CSV on the device: every password rated, reused ones and (optionally, HIBP k-anonymity) leaked ones flagged, export back in Chrome/Edge or Firefox CSV format. 8) FAQ on lawful recovery of your own accounts/devices/locks (Google, Apple, Microsoft, Android, Wi-Fi/router, BitLocker, 2FA backup codes, crypto wallet seed phrases, ZIP/PDF/Office files, TSA and combination locks, car keys, social networks, bank PIN) — official sources with links plus the latest web results, refreshed once per launch and stored offline. 15 interface languages. Also includes the other Pupikes tools described in the listing.
