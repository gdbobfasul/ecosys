# pupikes-medicines — Reviewer note (Huawei AppGallery)
Version 1.0024

## For reviewer
Reply to rule 3.1 ("Scan the medicine package → it does not list the main ingredients or any coherent, useful information") and rule 4.1 ("only simple content"). Version 1.0024 continues the 1.0023 fixes with a new, much more reliable first step (the BARCODE) and with links to the official leaflets in the user's language — the app stays compact: it carries basic data for the most common medicines and links out for everything else.

Root causes we found and fixed:
1. (1.0023) Text recognition used to be downloaded from a CDN at first scan. In the test region that download can fail, so the scan produced nothing. Now the OCR engine and the language models (Latin, Bulgarian/Russian Cyrillic, Simplified and Traditional Chinese) are BUNDLED INSIDE THE APP (public/ocr) — scanning works with no internet at all.
2. (1.0023) The result could be empty when the name was not matched. Now the app NEVER returns an empty result: a structured card always shows the text read from the box, tappable name candidates from the built-in databases, the type from the small print (form, route, for children/adults, strength, category) and a "Search by this name" button.
3. (1.0024) BARCODE FIRST, on the device: EAN-13, EAN-8, UPC-A/E, DataMatrix (GS1 AI 01) and QR codes are decoded from the photo by a bundled pure-JS decoder (@zxing/library, no network). The code is looked up in a BUILT-IN REGISTRY of about 100,000 products (openFDA NDC Directory: brand and generic name; US pharmaceutical UPC = "3" + NDC + check digit, plus the explicit UPC codes) — a match shows the medicine card instantly, before any text reading. If the code is not in the built-in registry, the app asks openFDA online (directly or through our relay) and otherwise falls back to reading the text, showing the code that was read.
4. (1.0024) "LEAFLET AND INFORMATION" on every card: instead of bundling full leaflets for all medicines in all languages, the card offers links in the interface language that open in the system browser — Wikipedia (exact page by the localized name from the built-in database, otherwise a search), DailyMed / FDA label (by NDC when a barcode was read), EMA (EU) and the national medicine registers/references (bg framar.bg, ru vidal.ru/rlsnet.ru, uk compendium.com.ua, de Gelbe Liste, fr base-donnees-publique.medicaments.gouv.fr, es CIMA/AEMPS, it Torrinomedica, pt Infomed/Infarmed, ar Webteb/Altibbi, hi 1mg, ja KEGG MEDICUS/PMDA, zh-Hant Hong Kong Drug Office). Only titles and addresses are stored; nothing is downloaded by the app.
5. (1.0024) A compact NAMES DICTIONARY (about 48,000 generic/INN and brand names: Wikidata INN/ATC/DrugBank items with labels in Latin script plus Bulgarian/Russian/Ukrainian/Arabic/Hindi/Japanese/Chinese spellings, and openFDA brand names; 1.5 MB) with tolerant search resolves brand names, foreign spellings and OCR mistakes to the medicine; the ~580 most common medicines keep their full built-in card (ingredients, form, indications, dosage, names in 15 languages), rarer ones get a short card plus the links above. The old 14 MB built-in copy of about 8,000 openFDA products was REMOVED from the app (the package is now ~23 MB instead of ~37 MB): these rarer products are looked up online in small per-letter parts (30–900 KB) from our own static server pupikes.app/medikit — only when the built-in data has no match and there is internet.
6. (1.0024) OPTIONAL server connection, OFF by default: the setting "Connect to the Pupikes server: search online and improve the shared database" (tab Scan). When switched on, unknown barcodes/names are looked up on our server and a recognised name/code is sent anonymously to improve the shared dictionary; small dictionary updates are fetched once per launch. Only medicine names and barcode numbers are sent — never photos, location or personal data; there is no account. The privacy policy lists this recipient. When the setting is off, the app never contacts our server.
7. (1.0024) Better text reading: the photo is also read after adaptive binarization with small print enlarged ×2, and Chinese/Japanese packages are also tried as vertical text. The "Main ingredients" line is always shown.

Content (rule 4.1), all on-device: Interactions (two medicines → built-in table of common interactions, severity and reason), Dosage calculator (common OTC medicines by weight/age), Intake schedule with daily reminders (local notifications) and a taken/not-taken log. Recognition straightens tilted photos (edge-orientation deskew) and reads packages at any angle. No account, no login, no ads.

## How to test
Preparation: choose a language → accept the legal screen → tick the medical disclaimer → the main screen with 4 tabs opens. Internet is NOT required for steps 1–2 and 4–7; the links in step 3 open web pages.

1. Barcode (tab "Scan") — a real sample is bundled, so no physical box is needed:
   - Tap "Try with a sample package" → four sample images appear. Tap the fourth, "Claritin 10 mg — barcode (UPC)".
   - Expected: status "Looking for a barcode…" for about a second, then immediately the card "Loratadine" (Claritin) with "Ingredients: loratadine", "Other names", "Barcode: 041100808707 · UPC-A", "In the registry: Claritin · Loratadine", the leaflet sections, the "Leaflet and information" links and the two buttons "Check interaction" / "Add to schedule". No text reading is needed for this sample.
   - Or tap "Photograph the box" and photograph the barcode of any US-market medicine box (e.g. Advil, Tylenol, Zyrtec) — the same instant card. For a box whose code is not in the registry the app continues with text reading and the card shows "Barcode … is not in the built-in registry, so the label text was read instead".
2. Scan a package by text (tab "Scan"):
   - Tap "Try with a sample package" → tap the first sample (Amoxicillin 500 mg capsules).
   - Expected: status "Reading… step 1/N" for a few seconds, then a card "Amoxicillin" with description, "Ingredients: amoxicillin", "Other names" (Amoxil, Ospamox, Flemoxin, 阿莫西林, Амоксициллин…), "Form", the leaflet sections and the two buttons.
   - Tap the second sample → card "Aspirin / acetylsalicylic acid" with the risky-ingredient warning "Dangerous on overdose"; the third → "Diclofenac".
   - Or photograph any medicine box (Latin, Cyrillic or Chinese label) — the same card appears. If the box cannot be identified, a card "Medicine not identified exactly — here is what was read" appears with the cleaned text, name candidates (tap one) and "Search by this name" — never an empty screen.
3. Links: on any card scroll to "Leaflet and information" → chips such as "Wikipedia (en) ↗", "DailyMed · FDA label (en) ↗", "EMA (EU) ↗" and, depending on the language, the national register (e.g. in German: "Gelbe Liste ↗"; in Russian: "vidal.ru ↗"). Tap one → it opens in the system browser on the page or search for that medicine. The line "Links open in the browser; the app does not store leaflets." explains the behaviour.
4. Type a name: in the field "or type the name from the box" type "Ibuprofen" (or "Нурофен", "布洛芬", "Panadol") → Search → full card. Type a brand name that is only in the dictionary, e.g. "Zyrtec-D", "Motrin IB" or "Ozempic" → the medicine is found (short card with generic name and links when it is not among the ~580 with full data); type a misspelt name, e.g. "Amoxiciline" → found by tolerant search; for an unknown word a "Did you mean:" list appears.
5. Tab "Interactions": type "ibuprofen" and "warfarin" → Check → red card "HIGH risk — avoid the combination, ask a doctor · Why: increased bleeding risk". Try "tramadol" + "sertraline" (serotonin syndrome), "omeprazole" + "clopidogrel" (reduced effect), "paracetamol" + "cetirizine" (no interaction in the table). Brand names and 15-language spellings work ("Nurofen" + "Аспирин").
6. Tab "Dosage": select Paracetamol, weight 20 kg, age 6 years, form "syrup 120 mg / 5 ml" → Calculate → "Single dose: 200–300 mg ≈ 8.3–12.5 ml", "Every 4–6 hours", "Maximum per 24 h: 1200 mg (4 doses)". Select Aspirin with age 6 → the app refuses ("not given under 16 years"). Select ORS → rehydration volumes.
7. Tab "Schedule": enter "Amoxicillin", dose "1 capsule", times 08:00 and 20:00, 7 days → "Save & set reminders" → the app asks for notification permission and confirms "Reminders are set on the device". The entry appears with today's times; tap a time to mark it taken; "Next dose" is shown; Delete removes the entry and its reminders.
8. Server setting (optional): in tab "Scan" the checkbox "Connect to the Pupikes server: search online and improve the shared database" is OFF by default and then the app makes no request to our server API. Tick it: small dictionary updates are fetched once (not repeatedly while the app is open); type a medicine that is not in the built-in data (e.g. "Hydravex") → Search → the card comes from our server ("Source: Pupikes server") with links; scan the Claritin barcode sample → the recognised code and the generic name ("041100808707 → loratadine") are sent anonymously. Only the medicine name / barcode number, its generic name and the interface language are sent — never photos, location or personal data; there is no account. Untick it → no further requests. The explanation is shown under the checkbox in all 15 languages and the privacy policy lists this recipient.
9. Language: the globe button at the top switches between the 15 languages; every label, including the barcode lines, the links section and the server setting, is translated.

Permissions: camera (through the system photo picker, only when the user taps "Photograph the box"), POST_NOTIFICATIONS (only when saving a schedule). Photos never leave the device; the barcode is decoded on the device.
