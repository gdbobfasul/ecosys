Core Descent es un rompecabezas de minería: excava hasta llegar al núcleo brillante de la Tierra. Cada nivel es un pozo de tierra, roca, mineral, cristal, magma y cuevas construido a mano. Elige la herramienta adecuada para cada obstáculo (pico y pala para piedra, un taladro para paredes sólidas, un traje térmico para lava, un detonador para pólvora, una bomba para túneles inundados, una cuerda para abismos y una lámpara para la oscuridad) y despeja un camino seguro hacia el fondo. Cada nivel tiene solución. Controles táctiles con una sola mano, completamente fuera de línea, sin cuentas.
