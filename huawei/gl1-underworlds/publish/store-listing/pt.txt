Core Descent é um quebra-cabeça de mineração: cave direto até o núcleo brilhante da Terra. Cada nível é um poço de solo, rocha, minério, cristal, magma e cavernas construído à mão. Escolha a ferramenta certa para cada obstáculo - picareta e pá para pedra, uma furadeira para paredes sólidas, uma roupa térmica para lava, um detonador para pólvora, uma bomba para túneis inundados, uma corda para abismos e uma lâmpada para a escuridão - e abra um caminho seguro até o fundo. Cada nível pode ser resolvido. Controles de toque com uma mão, totalmente offline, sem contas.
