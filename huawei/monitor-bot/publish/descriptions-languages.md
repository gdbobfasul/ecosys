```
Watch any website
```

```
Pupikes Site Monitor watches any website for you, with four tools. 1) Search now: type a site and a phrase and instantly see whether the text is present right now, like a quick search, with no alarm. 2) Daily text watch: add a site and a phrase and the app checks once a day whether that text appears; when it does, you get a notification and your chosen alarm music. 3) Daily image match: pick a reference image, and the app checks once a day whether an identical image (matched first by exact byte size and then byte for byte) appears on the site; on an exact match it alarms. 4) Daily status watch: add a site and be alerted the moment it changes between online and offline.
```
