# Skill Coach — Reviewer note (Huawei AppGallery)

## For reviewer (reply to rule 4.1 "offers only one type of content")
The app is NOT single-purpose. There is a tab bar at the top with TWO views; please tap both:

1. 🎯 **Наставник / Coach** — the AI skill mentor: pick a skill to master, describe your attempt, and get structured feedback and a step-by-step program path (10 minutes a day).

2. 🧰 **Инструменти / Tools** — tap this tab; it has THREE separate, fully-offline utilities in its own sub-tab bar:
   - 📚 **Библиотека / Library** — a built-in library of ready practice paths for common skills, with levels and concrete steps (no internet, no AI needed).
   - 🔥 **Серии / Streak & progress** — mark each day you practised; shows current streak, personal best, total days, last-7-day and last-30-day percentages and a 30-day calendar heatmap. Stored locally.
   - 🎲 **Предизвикателство / Challenge** — a random daily practice challenge with a re-roll button.

So the app offers distinct content types: an AI coach, a static skill library, a habit/streak tracker with a calendar, and a challenge generator. Everything works offline, on-device, with no account. All UI is localized into 15 languages (switch with the language control; every label, including the Tools sub-tabs, is translated).

## How to test
1. Choose a language → accept the legal screen.
2. In 🎯 Наставник: type a skill (e.g. "public speaking"), describe an attempt → you get structured feedback and the next step of a program.
3. Tap 🧰 Инструменти → 📚 Библиотека: pick a skill from the grid → a leveled practice path with concrete steps appears.
4. Tap 🔥 Серии → "✅ Отбележи днешно упражнение" (Mark today's practice) → the streak, totals and the 30-day calendar update.
5. Tap 🎲 Предизвикателство → a random challenge appears; use the re-roll button for another.
6. Switch the language with the top control → the whole UI, including the Tools sub-tabs, is translated.

No account, no login, no ads. All data stays on the device.
