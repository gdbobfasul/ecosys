Pupikes Auth & Passwords — зашифрованный менеджер паролей, двухфакторный аутентификатор (TOTP/HOTP/Steam) и конвертер ключей между приложениями — всё в одном сейфе на вашем устройстве, без аккаунта, сервера и рекламы.

Пароли: сайт, логин, пароль, другой код, заметки; импорт и экспорт из Chrome, Edge и Firefox (CSV); поиск дубликатов; глобальный поиск по всем разделам. 2FA: добавление камерой, по QR-картинке, вручную или по ссылке otpauth://; конвертация в обе стороны с Google Authenticator (миграционный QR), Aegis (в т. ч. зашифрованный), 2FAS (в т. ч. зашифрованный), список otpauth, JSON и QR-картинки в .zip. Крипто: seed-фразы, приватные ключи, ПИН-коды и адреса по 32 встроенным кошелькам (MetaMask, Ledger, Trezor, Binance, Trust Wallet…) плюс до 20 своих; отдельные разделы для SSH-доступов, EVM-сетей и ERC-20 токенов; QR-коллекция для привязки устройств.

НОВОЕ — раздел «Защита»: Аудит безопасности (утёкшие пароли через k-анонимность — наружу уходят только 5 символов хеша; слабые, повторяющиеся, без 2FA, старые → оценка и план действий); Проверка адреса против фишинга (двойники ваших сайтов, punycode, смешанные алфавиты, бренд как поддомен — полностью офлайн); Наследство — зашифрованный пакет с инструкциями для доверенного человека.

Всё хранится только в сейфе AES-256-GCM на устройстве (мастер-пароль + биометрия) и удаляется при удалении приложения. Интерфейс на 15 языках.
