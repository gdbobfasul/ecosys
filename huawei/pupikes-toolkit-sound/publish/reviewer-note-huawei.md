## For reviewer

To address the feature-depth note, a new offline "Tools" (Инструменти) section was added with real audio utilities built on the Web Audio API: a metronome (adjustable BPM with audible/visual beat), a tone generator/tuner reference (play sustained tones by note or frequency), and an interval timer with audible phase beeps. All tools are fully offline, work without an account or network, and are localized. This adds distinctive, deeper functionality that differentiates the app.
