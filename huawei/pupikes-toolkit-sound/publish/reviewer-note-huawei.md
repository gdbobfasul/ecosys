## For reviewer

This app's MAIN feature is Pupikes Sound Studio — sound and VOICE modulators and modifiers: load a file, record from the mic or use the example, STACK multiple effects, compare before/after and save, all on-device. This is NOT a generic audio converter; format conversion is a secondary tool.

An offline "Tools" (Инструменти) section adds further audio utilities built on the Web Audio API: a metronome (adjustable BPM with audible/visual beat), a tone generator/tuner reference (play sustained tones by note or frequency), and an interval timer with audible phase beeps. All tools are fully offline, work without an account or network, and are localized.
