# pupikes-toolkit-pictures — Reviewer note (Huawei AppGallery)
Version 1.0021

## For reviewer
Reply to rule 4.3 ("Shrink pictures (image compressor), similar to existing apps; improve interaction design and feature depth").

Version 1.0021 changes the core of the app. It is no longer an image compressor: the FIRST screen is now "Photo evidence" — photos as proof. You open a CASE (flat rental, car before a repair, delivery/parcel, repair works, meter readings, insurance damage) and add photos of the state "before", "after", damage, meter readings or documents. Every photo gets a SHA-256 fingerprint of its original bytes (the original file is kept unchanged on the device), a visible watermark with date, time, place and fingerprint, and an entry in a tamper-evident JOURNAL where every entry contains the fingerprint of the previous one. Later you can prove that a photo was not changed, see WHERE an edited copy was changed (difference map), and hand over a SIGNED PDF REPORT. The compressor, filters, crop, batch processing and EXIF removal remain as secondary tools (button "All tools" in the header). Everything works offline on the device; no account, nothing is uploaded. On first launch the app contains one clearly marked SAMPLE case with 5 generated photos (badge "sample", button "Delete sample") so every screen is populated immediately.

What is new (all on-device):
- Cases: list with thumbnails, type, number of photos, counters line and journal status ("intact"/"broken"); new case form (title, type, place/address).
- Case: add photos with the camera (system camera app) or from the gallery, choose what the photo shows (Before / After / Damage / Meter reading / Document / Other), note, meter value; automatic meter difference line ("Readings: 04512.7 → 04689.3 (difference +176.6)").
- Photo: watermark preview (date/time, place, SHA-256, journal number), full fingerprint, recorded time, EXIF capture date and device, location, size; "Save with watermark" (JPEG copy), "Save original (same fingerprint)", edit note, delete (the deletion is recorded in the journal).
- Verify: choose any photo file → its SHA-256 is looked up in the journal → "UNCHANGED ✓ identical to photo … recorded …" or "identical to a photo deleted on …"; if not identical → compare with an original → DIFFERENCE MAP (red = changed, yellow frame = area) with the changed percentage and a verdict: local change (retouch), whole-image change (filter/crop/other photo) or visually identical (only re-saved/compressed).
- Journal: hash chain of all actions (case created, photo added, note changed, photo deleted, copy saved, PDF created); "Check again" re-hashes every entry and every stored photo; editing/removing an entry or swapping a photo file is shown as "BROKEN at entry #N" / "photo no longer matches its fingerprint"; export as JSON.
- Signed PDF report: author and other party names, two signature pads (draw with a finger), cover page with case data, list of photos with fingerprints, report fingerprint (SHA-256 of all photo fingerprints + last journal entry), then the watermarked photos with their data; pages are rendered on canvas (so Chinese, Japanese, Hindi and Arabic text is printed correctly) and the fingerprints are also embedded as real PDF text. The PDF's own SHA-256 is shown and recorded in the journal.
- Settings: "Record location (GPS)" (off by default), show place / fingerprint on the watermark, your name for reports, storage used.

## How to test
1. Launch the app → choose a language → the first screen is "Photo evidence" with tabs Cases / Verify / Journal / Settings and one sample case "Flat rental — 5 Oak Street, flat 12" (badge "sample"); the counters line shows "1 cases · 5 photos · journal: 6 entries ✓ intact".
2. Tap the sample case → 5 photos (Before, Meter reading, Damage, Meter reading, After), each with a short SHA-256 and journal number; the yellow line shows "Readings: 04512.7 → 04689.3 (difference +176.6)".
3. Tap a photo → "Photo with watermark" shows the photo with the dark band (Recorded: date/time · tag, Location: coordinates · address, SHA-256 …, Journal #N). Tap "Save with watermark" → the share/save dialog opens with a JPEG; the status shows the fingerprint of the saved file. "Save original (same fingerprint)" saves the untouched file.
4. Back to the case → "Take photo" opens the system camera (or "From gallery" → pick 1–3 photos) → choose "Damage", type a note → the photos appear in the list with their fingerprints; the line "Added N photos to the journal." is shown.
5. Tab "Verify" → tap "Try with an example (retouched copy of a sample photo)" → the fingerprint is not in the journal → the app compares it with the original "Living room wall — at move-in" → difference map: the removed picture on the wall is marked red inside a yellow frame, "Changed: about 5% of the image area", verdict "LOCAL CHANGE". Then "Choose a photo to verify" → pick the original saved in step 3 → "UNCHANGED ✓ Identical to photo …".
6. Tab "Journal" → green "Journal intact: N entries; all M photos match their fingerprints"; the list shows each entry with its hash and the previous hash ("h … ← …").
7. Case → "PDF report" → type your name, draw a signature with a finger (and optionally the other party's) → "Create signed PDF" → the share/save dialog opens with the PDF; the status shows "PDF created — N pages. PDF fingerprint: …" and a new journal entry "PDF report created" appears.
8. Tab "Settings" → turn on "Record location (GPS) with new photos" → Android asks for location permission once → new photos get coordinates on the watermark and in the report. Turning it off stops using location.
9. Back on the case list → "Delete sample" removes the sample case (the deletion stays in the journal). Header button "⊞" (All tools) → grid with "Photo evidence" and "Photo tools" (compress with quality/format/max width, rotate/mirror, crop 1:1/4:3/3:4/16:9/9:16, exact size, 8 filters, batch, EXIF removed on save, before/after comparison). Header button 🌐 → language screen (15 languages).

Permissions: ACCESS_COARSE_LOCATION / ACCESS_FINE_LOCATION — only when the user turns on "Record location (GPS)" in Settings (off by default); used only to write coordinates into the watermark, the journal and the PDF report on the device — never sent anywhere. The camera is opened through the system camera app (no CAMERA permission). POST_NOTIFICATIONS — unchanged from previous versions. No internet is needed for any of the above.
