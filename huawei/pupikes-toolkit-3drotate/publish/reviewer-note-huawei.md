## For reviewer

To address the feature-depth note, a new offline "Tools" (Инструменти) section was added using the Canvas API: an image transformer (rotate/flip with live preview), a resizer (aspect-preserving with new dimensions/size), and an eyedropper color picker (HEX/RGB from the image). All tools are fully offline, work without an account or network, and are localized. This adds distinctive, deeper functionality that differentiates the app.
