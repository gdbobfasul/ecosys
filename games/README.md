# GL1 — Game Level 1 (демо версии)

Всяка папка `GL1-<име>` е демо на нова оригинална игра. Графиките в `assets/` са от СВОБОДНИ източници (CC0 / обществено достояние / свободни за търговия), сваляни и форматирани; после се преправят до неузнаваемост, за да станат уникални. Без векторни графики.

| Папка | Игра | Жанр |
|---|---|---|
| GL1-Candle | Свещта | flappy (един допир) |
| GL1-Flock | Ято | flappy за тълпа |
| GL1-Rewind | Обратното време | платформър |
| GL1-Seasons | Сезоните | походова стратегия |
| GL1-Underworlds | Подземни цивилизации | 4X |
| GL1-Bloodstream | Кръвоносна система | RTS |
| GL1-Shadow | Сянката | платформър |
| GL1-Gravity | Гравитацията | състезание |
| GL1-SoundOnly | Само звук | тактически шутър |
| GL1-Queue | Опашката | масово изкачване |
