# JobBot — бот за работа

Автоматизира **регистрация**, **търсене** и **кандидатстване** за работа, плюс **проверка на пощата** за отговори. Работи през твой истински браузър (постоянен профил, влизаш веднъж) — ботът се закача и попълва вместо теб.

Мишени по подразбиране: **alignerr.com**, **work.mercor.com**, **upwork.com** — но работи на всеки сайт (общ попълвач на форми).

## Твърди граници (ти контролираш)
- Нищо **не се подава** автоматично — ботът попълва и показва преглед; подава **само** с `--submit`.
- **Не отмята** сам съгласия/условия (GDPR/terms/лични данни) — това го правиш ти. Ако има неотметнато съгласие, `--submit` се отказва и те чака.
- При CAPTCHA или непознато задължително поле — спира и ти го показва (не гада).

## Подготовка (веднъж)
1. Попълни **`profile.json`** — имена, имейл, телефон, град, адрес, образование, опит, умения. В `answers` слагаш готови отговори на чести въпроси (напасват се по ключова дума от въпроса).
2. Сложи CV-то си в папка **`cv/`** и задай пътя в `profile.json` → `cv_file` (напр. `cv/CV.pdf`). По желание и мотивационно писмо → `cover_letter_file`.
3. Отвори браузъра и влез веднъж:
   ```
   node private/job-bot/job-bot-launch.cjs https://alignerr.com/
   ```
   Логни се (или създай акаунт ръчно, ако сайтът иска имейл-потвърждение) и остави браузъра отворен.

## Команди
```
node private/job-bot/job-bot.cjs register --url <сайт> [--submit]
node private/job-bot/job-bot.cjs search [--name <зап.>] | [--keywords ".." --location ".." [--url <сайт>] [--save <име>]] [--open N]
node private/job-bot/job-bot.cjs apply  --url <обява> [--cover <файл>] [--submit]
node private/job-bot/job-bot.cjs inbox  [--days 14] [--query "..."]
node private/job-bot/job-bot.cjs profile | searches
```

- **register** — отваря сайта, намира формата за регистрация, попълва данните, качва CV, отговаря на познати въпроси. Без `--submit` само попълва и прави преглед (+ снимка на екрана). С `--submit` подава — но се отказва, ако има неотметнати съгласия или празни задължителни полета.
- **search** — търси по ключови думи/локация. `--save <име>` запазва критериите (в `searches.json`); после `--name <име>` ги пуска пак. `--open N` отваря N-тата обява за кандидатстване.
- **apply** — кандидатства по обява (същият попълвач + CV, пак гейтнат с `--submit`).
- **inbox** — чете Gmail за отговори по кандидатури и ги дели на **позитивни/покани**, **откази**, **чакащи**. (Трябва Gmail да е логнат в същия браузър.)

## Отчети
Всичко пада в **`reports/`** — текстов отчет (какво е попълнено, какво чака теб, съгласия) + снимки на екрана преди/след.

## Паролата
Ако регистрацията иска парола, а в `profile.json` няма — ботът генерира силна, попълва я и я записва в `profile.json` → `password` и в отчета. Пази я.
