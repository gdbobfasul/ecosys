# Pupikes-Desk — нативна услуга за достъп преди вход (secure desktop)

Това е **опция „Б"** от разговора: достъп до **login/заключения екран** на Windows ОТДАЛЕЧЕНО, със
запазена парола (виждаш login екрана през Pupikes-Desk и набиваш паролата от разстояние).

Electron приложението НЕ може да стигне този екран — Windows го изолира в сесия 0 (secure desktop).
Единственият път е **услуга като LocalSystem**, която пуска агент в активната конзолна сесия и се
закача за **входния работен плот** (`OpenInputDesktop`/`SetThreadDesktop`) — вкл. Winlogon.

## Защо C# с вградения компилатор
Машината няма инсталиран dotnet/MSBuild/C++. Затова ползваме **вградения** `csc.exe` на .NET Framework
(`%WINDIR%\Microsoft.NET\Framework64\v4.0.30319\csc.exe`) — налице е на всеки Windows, **без инсталации**.

## Етапи
- **ЕТАП 1 — ГОТОВ (компилира се):** услугата пуска агента като SYSTEM в активната сесия; агентът се
  закача за входния десктоп (вкл. secure) и **заснема екрана в кадри** → `C:\ProgramData\PupikesDesk\frame.bmp`
  (~1/сек) + лог `service.log`. Това ДОКАЗВА, че защитеният екран се хваща. _Нужно е тестване на самата
  машина (иска администратор за инсталиране на услугата) — не може да се провери от средата за разработка._
- **ЕТАП 2 — следва:** вместо файл, кадрите отиват през сигналния сървър към Pupikes-Desk в реално време
  (JPEG/парчета по WebSocket), и обратно — мишка/клавиатура от Pupikes-Desk се инжектират на secure desktop
  (`SendInput` на закачения десктоп) → истинско въвеждане на паролата отдалечено.
- **ЕТАП 3 — следва:** чекбокс в Pupikes-Desk „достъп до login екрана", който инсталира/пуска услугата с
  еднократно UAC повишение (install.cmd), и я спира (uninstall.cmd).

## Билд и тест (на самата машина)
```
build.cmd        :: компилира PupikesDeskService.exe (вграден csc, без инсталации)
install.cmd      :: инсталира + пуска услугата (сам иска администратор през UAC)
                 :: после заключи с Win+L и виж C:\ProgramData\PupikesDesk\frame.bmp — трябва да хваща
                 :: заключения/login екран (доказателство за ЕТАП 1)
uninstall.cmd    :: спира и маха услугата
```
Конзолен тест без услуга (хваща само текущия десктоп, не secure — за бърза проверка на заснемането):
```
PupikesDeskService.exe --console
```

## Файлове
- `PupikesDeskService.cs` — услуга + агент + заснемане (P/Invoke към Win32).
- `build.cmd` / `install.cmd` / `uninstall.cmd` — компилиране и управление (с UAC).

## Честно за статуса
Етап 1 се **компилира** чисто и логиката следва документирания подход на такива инструменти (AnyDesk/
TeamViewer ползват същата идея — услуга + агент на входния десктоп). НО реалното хващане на secure desktop
трябва да се **потвърди на машината** (иска администраторски права и рестарт/заключване за проверка),
което не може да стане от средата за разработка. Етапи 2–3 са планирани и следват.
