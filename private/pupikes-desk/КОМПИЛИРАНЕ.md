# Pupikes-Desk — как да компилирам и пусна приложението

Pupikes-Desk (копие на AnyDesk) има **три форми**. Всичко готово пада в папка `release/`.

---

## 1. Уеб-версия (вече работи — нищо за компилиране)

Живата страница е на сървъра: **https://take.offbitch.com/desk/**
Вдига се от стартовото меню → **точка 88** (systemd `kcy-desk` :3017 + nginx `/desk/`).
Оттук телефон или браузър може да е КОНТРОЛЕР на отдалечен компютър.

---

## 2. Windows .exe (основната форма)

На Windows машина с инсталиран **Node.js**:

```
cd private/pupikes-desk
npm install          # еднократно — сваля Electron (иска интернет)
npm run dist         # компилира
```

Готово → в `release/`:
- **`Pupikes-Desk-Setup-1.0.0.exe`** — инсталатор (инсталира се като нормална програма);
- **`Pupikes-Desk-1.0.0-portable.exe`** — portable (пуска се директно, без инсталация).

**Пускане след компилиране:** двойно щракване върху .exe-то. Най-отгоре се показва
уникалният 9-цифрен номер + двете пароли (6 знака = само гледане, 18 знака = пълен достъп).

---

## 3. Android (телефонът като контролер)

На машина с инсталиран **Android SDK + JDK 21** (както за другите ни апове):

```
cd private/pupikes-desk
npm install          # еднократно
npm run android:add  # еднократно — създава android/ проекта
npm run android:apk  # компилира APK и го слага в release/
```

Готово → **`release/Pupikes-Desk-1.0.0-android-debug.apk`** (прехвърли на телефона и инсталирай).

> За подписан release APK вместо debug: отвори `android/` в Android Studio и пусни
> „Generate Signed Bundle / APK", или смени `assembleDebug` → `assembleRelease` след
> като добавиш ключ за подписване. После пак `node build-tools/collect-apk.cjs`.

---

## Локален тест без компилиране (по желание)

```
npm install
npm start            # пуска Electron приложението директно от кода
```
Вграденият signaling сървър тръгва на `ws://localhost:9000`. За връзка през нашия
сървър вместо локално: в приложението смени signaling адреса на
`wss://take.offbitch.com/desk/`.
