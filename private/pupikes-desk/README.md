# Pupikes-Desk (копие на AnyDesk)

Отдалечена връзка между два компютъра: **споделяне на екран**, **отдалечено управление на мишка/клавиатура** и **трансфер на файлове**. Electron + WebRTC. Потокът върви **директно между машините** (P2P); нашият сървър само ги сдвоява.

## Как работи
- Най-отгоре всеки компютър показва **уникалния си 9-цифрен номер** + **двете пароли** за достъп.
- **Само 2 нива на достъп** (не профили):
  - **НАБЛЮДЕНИЕ** — парола **6 знака** → другият само гледа екрана (без управление, без файлове).
  - **ПЪЛЕН ДОСТЪП** — парола **18 знака** → гледане + мишка/клавиатура + трансфер на файлове.
- Който иска да влезе, въвежда номера на другия + една от двете му пароли. Паролата определя нивото; гостът автоматично споделя екрана.

## Инсталиране и пускане

Папка: **`private/pupikes-desk`**. (Всички команди се пускат от нея.)

### 1) Signaling сървърът (винаги нужен — сдвоява двата компютъра)
```
cd private/pupikes-desk
node server/signal.cjs            # слуша на :9000; раздава и интерфейса на http://<този-компютър>:9000
```
Модулът `ws` вече е в хранилището (node намира `ws` от корена) — НЕ е нужен `npm install` за сървъра.
За реално ползване го качи на нашия сървър зад `wss://` (nginx) и сложи адреса в „Signaling адрес" в приложението.

### 2a) Windows десктоп приложение (пълно: споделя екран + управление + файлове)
```
cd private/pupikes-desk
npm install                       # тегли Electron + nut.js (иска интернет); еднократно
npm start                         # пуска приложението
```
Без `nut.js` (ако не се инсталира) работят гледане на екрана + файлове, но не и управление на мишка/клавиатура.
Пакет .exe: `npm run dist` (electron-builder).

### 2b) Телефон / браузър (КОНТРОЛЕР — гледаш и управляваш друг компютър)
Просто отвори в браузъра на телефона: `http://<компютъра-със-signaling>:9000` — зарежда същия интерфейс.
Android пакет (Capacitor): `capacitor.config.json` е готов (`webDir: renderer`); `npx cap add android` + билд. Телефонът е безплатен.

### Как се свързваш
Най-отгоре всеки компютър показва 9-цифрен номер + 2 пароли (6 знака = наблюдение, 18 знака = пълен достъп).
Въведи номера на другия + една от паролите му → „Свържи се".

## Части
- `server/signal.cjs` — signaling (ws); сдвоява по ID, релейва offer/answer/ICE. Качва се на нашия сървър.
- `electron/main.cjs` — прозорец, достъп до екрана (desktopCapturer), отдалечено управление (nut.js), запис на файлове.
- `electron/preload.cjs` — безопасен мост.
- `renderer/` — интерфейсът и WebRTC логиката.

## Плащане / активация (само Windows; телефонната версия е безплатна)
- Безплатно до **2 употреби**; след това иска активация.
- Плащане през **PayPal** → в приложението въвеждаш **номер на транзакцията + име на изпращача** → отключва (данните се пазят в `payments-claimed.json` в папката на приложението, за да ги провериш в PayPal).
- **Специален код** (твоят) → отключва веднага без плащане.
- Настройки (цена, PayPal имейл, брой безплатни, специален код) са в **`electron/license.cjs` → CONFIG**. ⚠ Потвърди/смени цената и специалния код там.

## Отдалечено управление
Нужен е `@nut-tree-fork/nut-js` (optional dependency). Без него работят гледане на екрана + трансфер на файлове, но не и управлението на мишка/клавиатура.
