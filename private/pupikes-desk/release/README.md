# release/ — готови за разпространение файлове на Pupikes-Desk

Тук падат компилираните приложения. Папката се пълни от командите за компилиране
(виж `../КОМПИЛИРАНЕ.md`). Нищо тук не се пише на ръка.

Какво се появява след компилиране:

| Файл | Какво е | Команда |
|------|---------|---------|
| `Pupikes-Desk-Setup-1.0.0.exe` | Windows инсталатор (NSIS) | `npm run dist` |
| `Pupikes-Desk-1.0.0-portable.exe` | Windows portable (без инсталация) | `npm run dist` |
| `Pupikes-Desk-1.0.0-android-debug.apk` | Android приложение | `npm run android:apk` |

Уеб-версията НЕ се компилира тук — тя е живата страница на сървъра:
**https://take.offbitch.com/desk/** (вдига се от стартовото меню, точка 88).
