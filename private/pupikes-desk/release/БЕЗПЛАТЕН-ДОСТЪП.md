```

```

С този код отключваш приложението **без плащане, завинаги на съответния компютър**.

## Как се въвежда

1. Отвори Pupikes-Desk.
2. Най-горе в лентата натисни **„🔑 въведи код за безплатен достъп"**.
   - (Или изчакай заключващия екран, който се появява след 2-рата употреба.)
3. В полето **„Специален код"** напиши: `PUPIKES-FREE-2026`
4. Натисни **„Отключи с код"**.
5. Готово — приложението е отключено на този компютър завинаги.

## Къде се пази всичко — файлът `pupikes-desk.json`

До приложението (в същата папка, където е .exe-то) се създава файл **`pupikes-desk.json`**. В него стоят:

```json
{
  "id": "123456789",              // твоят номер (9 цифри)
  "viewPassword": "Ab12Cd",       // парола за НАБЛЮДЕНИЕ (само гледане)
  "fullPassword": "Ab12Cd34Ef56Gh78",  // парола за ПЪЛЕН ДОСТЪП (гледане + управление + файлове)
  "activated": true,              // безплатен достъп (след въвеждане на кода)
  "method": "owner"
}
```

Правила за този файл:
- Стои на компютъра и важи, **докато не изтриеш файла**. Изтриеш ли го → при следващо пускане се дават **нов номер и нови пароли**.
- Можеш да го **редактираш на ръка**:
  - Сложиш ли **нов номер** и той е свободен → при следващо пускане компютърът работи с него.
  - Ако номерът е **зает** (пуснат на друг компютър в момента) → приложението не стартира с него, докато не смениш номера или изтриеш файла.
  - Смениш ли **паролата** във файла → свързването става с новата парола.
- Липсва ли някое поле → генерира се ново автоматично.
- Безплатният достъп (кодът) също се пази тук (`activated`) — стои, докато не изтриеш файла.

## Важно

- Кодът важи **за всеки компютър поотделно** — въведи го на всяка машина, на която искаш безплатен достъп.
- **Телефонната версия (Android) е безплатна** — там не се иска код.
- Безплатните употреби без код са **2**; след това се иска плащане или код.
