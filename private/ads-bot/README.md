# AdsBot — бот за ОБЯВИ

Регистрира профили и **пуска обяви** в сайтове с обяви. Взема механизма от JobBot (попълвач на форми,
регистрация, submit-гейт), но е **напълно отделен**: отделен браузър-профил (порт 9225), отделна
самоличност и имейл, **без CV и снимка-аватар** по подразбиране. Данните в обявите често са измислени —
ти решаваш какво слагаш (ботът не измисля лични данни сам).

## Твърди граници (както при JobBot)
- Нищо не се публикува автоматично — `post`/`register` само попълват и правят преглед; публикуват **само** с `--submit`.
- Не отмята сам съгласия/условия; при неотметнато съгласие `--submit` се отказва и те чака.
- При CAPTCHA/непознато поле — спира и показва.

## Подготовка (веднъж)
1. Попълни **`adsdata/poster.json`** — самоличност + **отделен имейл** за обявите (паролата се генерира сама, ако липсва).
2. Попълни **`adsdata/ads.json`** — заглавие, описание, цена, категория, град, (по желание) снимки.
3. Влез веднъж в браузъра:
   ```
   node private/ads-bot/ads-bot-launch.cjs https://www.olx.bg/
   ```

## Намиране на сайтове (критерий: държава → тип)
```
node private/ads-bot/ads-bot.cjs sites --country bg --type имоти
```
`sites.json` е каталогът (countries → държава → тип → {име: url}); добавяй свободно.

## Команди
```
node private/ads-bot/ads-bot.cjs sites    [--country <държава>] [--type <тип>]
node private/ads-bot/ads-bot.cjs register --url <сайт> [--submit]
node private/ads-bot/ads-bot.cjs post     --url <страница за обява> [--submit]
node private/ads-bot/ads-bot.cjs check    (обхожда регистрираните → известява с попъп + имейл)
node private/ads-bot/ads-bot.cjs see      --url <сайт>   (ботът „вижда" страницата)
```

- **register** — намира формата за регистрация, попълва данните от `poster.json`, отговаря на познати въпроси; с `--submit` подава (гейтнато от съгласия).
- **post** — отваря страницата за обява, опитва да стигне формата „Нова обява", попълва полетата от `ads.json` (по ключови думи), качва снимки; с `--submit` публикува.
- **check** — минава по `registered-sites.json` (пълни се при register) и известява с Windows попъп + имейл до `notify_email`.

## Отчети
Всичко пада в `reports/` — текстов отчет + снимки на екрана.
