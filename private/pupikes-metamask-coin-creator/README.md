# PupikesMetamaskCoinCreator

Бот, на който **ти избираш само детайлите**, а той прави **всичко сам**: има си собствен MetaMask акаунт,
пуска токени от меню, следи ги, прави статистики, **пази ги от кражба**, управлява цената (ликвидност/изгаряне/
изкупуване), продава по твоя команда и тегли парите към твой акаунт. Ти имаш достъп до същия акаунт → гледаш и
контролираш.

## Как работи (целият поток)
1. **Портфейлът на бота** — `node vault.js new` създава MetaMask акаунт (24-думна сийд фраза + парола, пази ги
   в `wallet/`). Ти внасяш същия акаунт в MetaMask → имаш достъп (за продажба/теглене) и гледаш активността.
2. **Зареждаш газ/капитал** — пращаш напр. ~200$ в BNB на адреса на бота (`node bot.js wallet` го показва).
3. **Избираш токен от менюто** — `node bot.js menu` (10 токена, всеки със своя специфичност) → `node bot.js create <id>`.
   Ботът го пуска, задава защита на трезора и (на реална мрежа) сам зарежда пазача с газ.
4. **Пускаш пазар** — `node bot.js liquidity <id> <bnb> <tokens>` (PancakeSwap) → токенът има цена.
5. **Ботът следи и пази** — `node bot.js monitor` авто-отменя подозрителни (кражби); `node bot.js stats <id>`
   записва цената във времето; `node bot.js advise <id>` предлага легитимни ходове (изгаряне/ликвидност/изкупуване).
6. **Продаваш когато решиш** — `node bot.js sell <id> <tokens>` (токени → BNB в бота) → `node bot.js withdraw <bnb> <твой-адрес>`.

## Менюто — 10 токена, всеки с уникалност
`node bot.js menu`. Всички работят нормално като ERC-20, но всеки има своя черта:
guard 🛡 (анти-кражба за всички), ember 🔥 (1% изгаряне), harvest 🏦 (2% фонд), fair 🐋 (анти-кит),
shield 🛡+🏦, nova ⚖ (балансиран), green 💚 (благотворителност), pulse 🔥+🛡, loyal 🎁, aegis 🏛 (дълъг таймлок).
Флагман near-unique черта = **🛡 Vault Guard**: голям превод се задържа и може да се отмени → откраднат ключ не източва.

## Команди
```
node vault.js new | show | exportkey        # портфейл на бота (exportkey → за MetaMask Import Account)
node bot.js menu                            # каталог с 10-те токена
node bot.js create <id>                     # пуска избрания токен
node bot.js list | status <id> | wallet     # пуснати / инфо / портфейл+баланс
node bot.js monitor [id]                    # ПАЗИ: авто-отменя кражби от трезора
node bot.js liquidity <id> <bnb> <tokens>   # пуска пазар (ликвидност)
node bot.js price <id> | stats <id>         # цена / статистика във времето (× спрямо старта)
node bot.js advise <id>                     # съветник: легитимни ходове за качване на цената
node bot.js buy <id> <bnb>                  # [демо] купи (симулира търсене на testnet)
node bot.js sell <id> <tokens>              # продай токени → BNB (в бота)
node bot.js burn <id> <tokens>              # изгори от трезора (дефлация)
node bot.js withdraw <bnb> <адрес>          # тегли BNB към твой друг акаунт
node watch.js                               # ВИДИМО: отваря MetaMask да гледаш транзакциите на живо
```

## Мрежа
`config.json` → `activeNetwork` (`bscTestnet` за тест / `bscMainnet` за реално). `walletMode:"vault"` = ползва
портфейла на бота (`wallet/`). Всеки токен се записва в `deployments/<мрежа>-<id>.json`.

## Да ГЛЕДАШ бота в MetaMask
Ботът подписва бързо и надеждно сам. За да гледаш на живо: внеси акаунта му в MetaMask (`node vault.js exportkey`
→ MetaMask → Import Account → Private key; **добавя** акаунт, не трие твоя), добави мрежата + токените, и гледай
раздела **Activity** — всяко действие на бота (пускане/купуване/продажба/изгаряне/теглене) се появява веднага.
`node watch.js` отваря отделен MetaMask профил и ти показва точните адреси/мрежа за добавяне.

## Тествано на живо (bscTestnet, 04.09.2026)
Реален deploy на PGC (`0x78E2…081f`) и EMBR (`0x9df7…D814`); пуснат пазар; симулирано търсене → цена **×4.83**;
изгаряне 1M→900k; продажба на токени → BNB; теглене към друг акаунт; monitor **отмени симулирана кражба** и върна
трезора. Контракт: 16/16 (feature) + 10/10 (guard) теста.

## Честно за „5×"
Ботът дава всички легитимни лостове (ликвидност, прозрачно изгаряне, изкупуване, статистики, съветник). Реалният
драстичен ръст обаче идва от **истинско търсене** (полезност, общност, листване), не от трик. Токеномиката помага,
но не замества търсенето. Механизми за изкуствено надуване на цената пред реални инвеститори са манипулация — не ги правим.

## Сигурност
`wallet/` (сийд, ключове, keystore) е в `.gitignore` — не влиза в git. На mainnet дръж сийда офлайн: който го има,
управлява акаунта. Таксите/лимитите на токените са **непроменяеми** след пускане (без „rug"/honeypot); собственикът
няма опасни правомощия (не може да пипа чужди баланси, да пауз-ва или да мени такси).
