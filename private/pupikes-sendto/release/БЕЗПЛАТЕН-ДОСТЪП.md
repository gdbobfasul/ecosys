# PupikesSendTo — безплатен достъп (без плащане)

## Специален код

```
PUPIKES-FREE-2026
```

С този код отключваш **уеб-страницата без плащане** на съответното устройство/мрежа.

## Как се въвежда (уеб-страницата)

1. Отвори уеб-страницата (напр. https://take.offbitch.com/sendto/).
2. Най-долу натисни **„🔑 въведи код за безплатен достъп"**.
   - (Или изчакай заключващия екран, който се появява след 2-рото отваряне от същото IP — там също има поле за код.)
3. В полето напиши: `PUPIKES-FREE-2026`
4. Натисни **„Отключи с код"**.
5. Готово — достъпът е безплатен на това устройство.

## Важно

- **Мобилното приложение (Android) е напълно безплатно** — там не се иска нито код, нито плащане.
- Заключването е само на **уеб-страницата**, и то след **2 безплатни отваряния** от едно IP.
- Кодът отключва за съответното устройство/мрежа (IP).
