# release/ — готови за разпространение файлове на PupikesSendTo

Тук пада компилираното Android приложение. Папката се пълни от командата за
компилиране (виж `../КОМПИЛИРАНЕ.md`). Нищо тук не се пише на ръка.

| Файл | Какво е | Команда |
|------|---------|---------|
| `PupikesSendTo-1.0.0-android-debug.apk` | Android приложение (безплатно) | `npm run android:apk` |

Уеб-версията НЕ се компилира тук — тя е живата страница на сървъра:
**https://take.offbitch.com/sendto/** (вдига се от стартовото меню, точка 87).
Windows .exe няма — PupikesSendTo е само телефон + уеб.
