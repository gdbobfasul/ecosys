# PupikesSendTo (копие на Send Anywhere)

Трансфер на файлове между две устройства с **6-цифрен код**. Файлът върви **директно P2P** (WebRTC); сървърът само сдвоява устройствата и раздава уеб-страницата.

## Части
- `server/server.cjs` — HTTP (раздава `web/`) + signaling (ws) по 6-цифрен код + **заключване по IP** (безплатно 2 отваряния/IP, после плащане) + активация.
- `web/index.html` + `web/app.js` — приложението (Изпрати/Получи).
- `web/paywall.html` — заключващ екран (плащане през PayPal → транзакция+изпращач, или специален код).
- `android/` — (следва) Capacitor обвивка на `web/`, **безплатна** (сочи `window.PUPIKES_SERVER` към нашия сървър за сигнализация; без IP-заключване).

## Инсталиране и пускане

Папка: **`private/pupikes-sendto`**.

### Сървър + уеб-страница
```
cd private/pupikes-sendto
node server/server.cjs            # слуша на :3015 (раздава уеб-страницата + сигнализация)
```
`ws` се намира от корена на хранилището — НЕ е нужен `npm install`.
Отвори `http://<този-компютър>:3015` на ДВЕ устройства в мрежата: на едното „Изпрати" (дава 6-цифрен код), на другото „Получи" (въвеждаш кода). Файлът минава директно между тях (P2P).
За реално ползване: качи на нашия сървър зад `https://` + `wss://` (nginx).

### Мобилно приложение (Android, безплатно)
`capacitor.config.json` е готов (`webDir: web`). Стъпки: `npm install @capacitor/core @capacitor/cli @capacitor/android` → `npx cap add android` → в `web/config.js` сложи `window.PUPIKES_SERVER='https://<нашия-домейн>'` → билд.

### Заключване (само уеб-страницата)
Безплатно 2 отваряния от едно IP; след това paywall (плащане през PayPal → номер на транзакция + изпращач, или специален код). Мобилното приложение няма заключване.

## Монетизация
- **Мобилно приложение — безплатно.**
- **Уеб-страница** — безплатна 2 отваряния от едно IP; след това `paywall.html`: плащане през PayPal → въвеждаш **номер на транзакцията + име на изпращача** (пазят се в `server/data/activated.json` за проверка). **Специален код** → безплатно.
- Настройки в `server/server.cjs → CONFIG` (PAYPAL_EMAIL, PRICE, FREE_OPENS=2, OWNER_CODE). ⚠ Потвърди цената и кода.
