# PupikesSendTo — как да компилирам и пусна приложението

PupikesSendTo (копие на Send Anywhere) има **две форми**: уеб (вече живо) и Android.
Windows .exe няма. Всичко готово пада в папка `release/`.

---

## 1. Уеб-версия (вече работи — нищо за компилиране)

Живата страница е на сървъра: **https://take.offbitch.com/sendto/**
Вдига се от стартовото меню → **точка 87** (systemd `kcy-sendto` :3016 + nginx `/sendto/`).
Отваряш страницата на две устройства → сдвояваш по 6-цифрен код → файловете вървят
директно P2P (не през сървъра). Безплатно до 2 отваряния от същото IP, после плащане.

---

## 2. Android (безплатното мобилно приложение)

На машина с инсталиран **Android SDK + JDK 21** (както за другите ни апове):

```
cd private/pupikes-sendto
npm install          # еднократно
npm run android:add  # еднократно — създава android/ проекта
npm run android:apk  # компилира APK и го слага в release/
```

Готово → **`release/PupikesSendTo-1.0.0-android-debug.apk`** (прехвърли на телефона и инсталирай).

Мобилното приложение сочи към нашия сървър за сигнализация (`web/config.js` →
`window.PUPIKES_SERVER`). Мобилната версия е БЕЗПЛАТНА (без заключване по IP).

> За подписан release APK вместо debug: отвори `android/` в Android Studio →
> „Generate Signed Bundle / APK", или смени `assembleDebug` → `assembleRelease`
> след добавяне на ключ. После пак `node build-tools/collect-apk.cjs`.

---

## Локален тест на сървъра без компилиране (по желание)

```
npm install
npm start            # пуска сървъра (уеб + сигнализация) на http://localhost:3016
```
Отвори http://localhost:3016 на две устройства в същата мрежа за тест.
