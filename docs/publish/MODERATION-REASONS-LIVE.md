### NewsLator

> Приложение не прошло модерацию из-за некорректных скриншотов. Скриншоты должны отображать актуальную механику и функциональность. Недопустимо формирование ленты скриншотов, состоящей только из артов или элементов, не относящихся к интерфейсу приложения. В случае с игровыми приложениями скриншоты должны отображать актуальный уровень графики. Просим добавить реальные скриншоты из приложения. Подробнее о требованиях к приложению (п. 6.6 Правил модерации RuStore): https://www.rustore.ru/help/developers/publishing-and-verifying-apps/requirement-apps Expand all text
