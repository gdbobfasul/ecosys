Pupikes टेक्स्ट टूलकिट — संपूर्ण टेक्स्ट वर्कबेंच — ऑफ़लाइन, आपके डिवाइस पर।

शामिल टूल:
• टेक्स्ट टूल — काउंटर, फ़ॉर्मेटिंग, Base64
• केस और पंक्तियाँ — बड़े/छोटे/शीर्षक, क्रम, डुप्लिकेट, नंबरिंग, slug
• एन्कोड/डिकोड — URL, HTML, ROT13, मोर्स, बाइनरी, हेक्स
• जनरेटर — पासवर्ड, UUID, Lorem ipsum, SHA हैश
• निकालें — ईमेल, URL, संख्याएं, हैशटैग, मेंशन, IP
• डिफ़ — दो टेक्स्ट पंक्ति-दर-पंक्ति तुलना — जोड़ा/हटाया
• यूनिकोड शैली — बोल्ड, स्ट्राइक, रेखांकित, चौड़ा — सोशल मीडिया हेतु
• JSON / CSV — JSON फ़ॉर्मेट/मिनिफ़ाई/जाँच और JSON↔CSV
• शब्द आवृत्ति — शीर्ष शब्द बार के साथ + कुल/अद्वितीय/वर्ण
• रोमन अंक — संख्या ↔ रोमन (1–3999), स्वतः पहचान
• संख्या आधार — बाइनरी / ऑक्टल / दशमलव / हेक्स (BigInt)
• रैप और उपसर्ग — N वर्ण पर रैप, प्रति पंक्ति उपसर्ग (उद्धरण/टिप्पणी), अनरैप
• रंग — HEX ↔ RGB ↔ HSL स्वैच और पिकर के साथ
• टाइमस्टैम्प — Unix ↔ तिथि (स्थानीय/UTC/ISO), “अभी” बटन

कोई पॉप-अप विज्ञापन नहीं, कोई ट्रैकिंग नहीं — आपका डेटा आपके डिवाइस पर रहता है।
