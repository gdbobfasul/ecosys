Как да си вземеш ключ (веднъж):
  1. Отвори console.anthropic.com и влез/регистрирай се.
  2. Меню API Keys → Create Key.
  3. Копирай ключа (sk-ant-…) и го постави в полето горе.
  4. Натисни „Запази“. Ключът стои само на това устройство.

Програмата се плаща еднократно към собственика. ИИ работи през твоя ключ/акаунт и се харчи само с твое одобрение.
